 پشتیبانی از ارسال فایل (sendfile)
استفاده از syscall sendfile برای ارسال فایل‌های استاتیک (مثل عکس، CSS، JS) بدون کپی اضافی در user space.
مزیت: سرعت و مصرف حافظه کمتر.
2. پشتیبانی از TCP Fast Open
فعال‌سازی TCP Fast Open برای کاهش latency در اتصال‌های جدید.
نیاز به setsockopt و kernel support.
3. پشتیبانی از SO_REUSEPORT
استفاده از SO_REUSEPORT برای اجرای چندین instance سرور روی یک پورت (برای multi-core scaling).
4. پشتیبانی از epoll edge-triggered و one-shot
استفاده از EPOLLET (edge-triggered) و EPOLLONESHOT برای کنترل دقیق‌تر eventها و جلوگیری از race condition.
5. پشتیبانی از SIGPIPE و مدیریت سیگنال‌ها
مدیریت سیگنال‌هایی مثل SIGPIPE (که موقع قطع ناگهانی کلاینت رخ می‌دهد) با signal handler یا MSG_NOSIGNAL.
6. پشتیبانی از TCP_NODELAY
غیرفعال کردن Nagle’s algorithm با setsockopt (برای کاهش latency در ارسال داده‌های کوچک).
7. پشتیبانی از محدودیت منابع (Resource Limits)
استفاده از setrlimit برای محدود کردن تعداد فایل‌های باز یا مصرف حافظه سرور.
8. پشتیبانی از IPv6
اضافه کردن قابلیت listen روی IPv6 علاوه بر IPv4.
9. پشتیبانی از Access Log و Error Log با syslog
ارسال لاگ‌ها به syslog سیستم‌عامل به جای std::cout.
10. پشتیبانی از TLS (با کتابخانه‌هایی مثل OpenSSL)
اضافه کردن HTTPS با استفاده از کتابخانه‌های سطح پایین.
11. پشتیبانی از accept4 و non-blocking accept
استفاده از accept4 به جای accept برای تنظیم non-blocking در همان لحظه‌ی accept.
12. پشتیبانی از SO_RCVBUF و SO_SNDBUF
تنظیم سایز بافرهای دریافت و ارسال سوکت برای بهینه‌سازی performance.
