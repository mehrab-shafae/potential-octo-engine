 یک پروژه مخصوص لینوکس با io_uring پیاده سازی کنیم برای ارتباط با بخش اصلیمون. فعلا بخش اصلیمون رو اینجا نداریم اما باید در ابتدا ارتباط ها را مدیریت کنیم که خیلی برای ما مهم هست برای high performance بودن برنامه و همزمانی و بلاک نشدن I/O. برای ما throughput و low-latency و ziro overhead حرف اول را میزند.
نمیخوام تند رفتار کنیم و هر فیچر بی هدفی رو اضافه کنیم. باید با دقت پیش بریم و تک تک خط ها رو بررسی کنیم.
